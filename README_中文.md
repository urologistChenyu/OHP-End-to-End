# 上传版本：使用与文件范围

这是带必需运行库的Windows便携版本，已剔除旧环境中的R、编译库、无关框架和重复资料。原始工程不改动，也不复制验证病例、DICOM、人工掩膜、临床病例表或测试日志。

完整保留：自动勾画＋人工掩膜双入口，四临床输入、五分支等权、35.3054%工作点、DICOM文件上传、结果导出和已完成批次恢复。2D使用ACC第36轮，2.5D使用ACC第16轮，不使用共享旧assets中的epoch23。

使用时复制整个文件夹到新电脑的可写目录，双击 OHP.exe；也可使用“启动OHP.cmd”或“start_windows.cmd”查看诊断。无需系统预装Python，不依赖原电脑G盘。完整交付已配齐运行依赖，正常使用无需联网；仅依赖修复时需要联网。完整英文运行说明见USER_MANUAL_EN.md。

首次使用：选择同一CT序列的完整DICOM数据文件，确认病例ID，填写或导入Age、Tumorsize、NEUT、LYMPH四项临床输入；选择自动勾画，或提供与CT对应的人工肿瘤掩膜；指定新的输出目录后运行。完成后可查看CT与掩膜叠加、五分支概率及最终OHP百分比，并重新打开已有批次。没有合格掩膜的病例会提示人工处理，不强行给出概率。

Python 3.9用于保持历史组学与已保存scikit-learn模型的数值兼容，不能直接删掉这一环境的依赖；其旧torch、R和其他无关包没有列入新版安装。Python 3.12用于英文界面、DICOM和GPU。所有模型路径已改成包内相对路径，跨电脑不需要原G盘目录。

建议配置：32 GB内存、12 GB显存NVIDIA显卡、逐例运行、安装依赖后保留20 GB工作空间；实际实测见RESOURCE_REPORT.md。未把建议值写成已经验证的最低配置。

本轮已在独立迁移副本中从DICOM重新计算4例：人工掩膜入口3例，自动勾画入口1例。四例五分支及融合概率与各自对应的原软件结果完全一致，最大差异为0，分类一致。逐例结果见VALIDATION_CASES.csv，验证方式及范围见VALIDATION.md。验收为同一台实体电脑上的独立路径、独立运行库测试。

若无法启动，使用start_windows.cmd查看错误；OHP.exe启动异常也会记录到outputs/startup_error.log。需要明确使用CPU时可运行start_cpu.cmd，自动勾画会明显慢于GPU。切勿只拷走OHP.exe，也不要直接在压缩包预览窗口内运行。

模型内保留的11.8 MB生境KNN填补器含296×5502数值供体特征矩阵，这是缺亚区时保持结果一致所必需，不是日志或重复数据；其中不含病例ID、姓名、原图和标签。不能为了体积小直接移除。

代码按MIT整理，KiTS21第三方预训练权重按Zenodo标明的CC BY 4.0保留来源和署名。250 MB权重不能用普通Git直接提交，采用Git LFS、Release或Zenodo。当前只在本机整理，尚未替你公开上传。

## v1.1.0 可选本地设置

新增 Local Settings 页签，可配置分类阈值、使用本地带结局数据拟合截距，或进行带明确假设的患病率情景调整。默认仍使用原模型概率和原阈值；本地调整结果另行导出，原始预测、五分支贡献与权重均保留。该功能的数值验证不等同于外部临床有效性验证。完整说明见 LOCAL_SETTINGS.md。
