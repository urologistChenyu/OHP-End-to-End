# OHP 端到端桌面软件 v1.0

下载完整的三个 Windows 压缩包，并解压到同一目录。进入 02_End_to_End 文件夹，双击 OHP.exe。无需另外安装 Python 或 OneKey。请完整保留 runtime、models、configs、pipeline 等文件夹。

软件支持 DICOM 输入、自动分割或医师审核掩膜输入、五分支风险计算和结果导出。Local Settings 页签支持自定义分类阈值、本地带结局数据的截距拟合及带适用假设的患病率情景调整。默认概率和阈值保持固定；可选调整结果另行显示和导出。

完整说明见 USER_MANUAL_EN.md 和 LOCAL_SETTINGS.md。软件及模型资源见 https://github.com/urologistChenyu/OHP-End-to-End/releases/tag/v1.0 。
